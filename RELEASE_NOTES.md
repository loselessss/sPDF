# sPDF Release Notes

Release date: 2026-08-28

## 1.16.7 Improvement

- The integrated print window now uses the same Fluent card design as the rest of sPDF.

## 1.16.6 Improvement

- The integrated print window now supports Auto, Portrait, and Landscape paper orientation.

## 1.16.5 Fix

- Removed the empty strip below the document status bar.

## 1.16.4 Improvement

- Ctrl+P now opens one print window containing the preview, printer, range, order, copies, and one-sided or duplex settings.

## 1.16.3 Improvement

- The top-level Page menu is now named Page Organization for clearer navigation.

## 1.16.2 Fix

- The unsaved-changes dialog now shows Save, Don't Save, and Cancel in the selected interface language.

## 1.16.1 Improvements

- Sidebar thumbnails are now navigation-only. Click a precise point to move around a zoomed page; use the page organizer when reordering pages.

## 1.16.0 Highlights

- Use Alt+Left / Alt+Right to return to earlier views, and reopen documents at the last page, zoom, and scroll position.
- Add bookmarks with Ctrl+B; rename, delete, and drag them in the sidebar.
- Crop page margins by dragging a preview area and applying it to the current page, a range, or all pages. Bookmark and crop edits can be undone.
- Recover unsaved work after an interrupted standalone session from separate copies refreshed every 30 seconds. Recovered documents use Save As first; protected PDFs and copies over 512 MB are excluded.
- Windows Explorer now labels the registered file type simply as PDF.
- Temporary installer and interrupted-download files are removed after the updated application starts.
- Import nested bookmarks from TXT, add adjustable text watermarks, and convert images to PDF or PDF pages to PNG/JPEG.
- Preview print output and choose one-sided, long-edge duplex, or short-edge duplex printing.
- Native Windows file dialogs and cached, adaptive zoom rendering make everyday file and zoom operations feel more responsive.
